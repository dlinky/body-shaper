# 레이아웃 명세서

# 1. 공통 레이아웃

| 영역        | 구성                                                  | 동작                                                     |
| ----------- | ----------------------------------------------------- | -------------------------------------------------------- |
| 탑바        | 햄버거 버튼(좌), 타이틀(중앙), 설정 버튼(우)          | 모든 화면에 고정 표시                                    |
| 사이드바    | 메뉴 4개: 데이터 입력, 대시보드, 체형 기록, 운동 기록 | 햄버거 클릭 시 왼쪽에서 슬라이드, 바깥 영역 클릭 시 닫힘 |
| 메인 컨텐츠 | 현재 메뉴에 해당하는 화면                             | 메뉴 선택 시 교체                                        |

# 2. 데이터 입력 화면 (기본 화면)

**목적**: 오늘 하루의 체형기록과 운동기록을 입력하고 저장한다.

## 2-1. 구성

- 체형기록 폼 (기록일자는 기본값이 오늘)
- 운동기록 폼 (운동 선택, 무게, 세트별 횟수)

## 2-2. 폼 상태

| 상태      | 화면                                              | 버튼                   |
| --------- | ------------------------------------------------- | ---------------------- |
| 입력 중   | 입력창                                            | [임시저장] [저장 완료] |
| 임시저장  | 입력창 (값 유지, "임시저장됨" 표시)               | [임시저장] [저장 완료] |
| 저장 완료 | 입력값이 텍스트로 바뀜, 옆에 비교 어노테이션 표시 | [수정]                 |
| 수정 중   | 다시 입력창으로 전환                              | [덮어쓰기 저장]        |

데이터에는 status: "draft" | "saved" 필드를 추가해야 해요.

## 2-3. 비교 어노테이션 (저장 완료 상태에서만)

| 항목        | 예시 표시 | 계산                |
| ----------- | --------- | ------------------- |
| 어제 대비   | ▼ 0.3kg   | 오늘 값 − 어제 값   |
| 지난주 대비 | ▲ 0.5kg   | 오늘 값 − 7일 전 값 |

- 이전 값이 없으면 -로 표시해요.
- 저장하지 않고 계산만 해요. (증감은 저장하지 않는다는 앞선 원칙과 같아요.)

# 3. 대시보드 화면

## 3-1. 추이 차트 (상단)

- 종류: 꺾은선 그래프
- 선 2개: 실제 측정값, 목표값(수평선)
- 필터: 수치 1개를 선택해서 보는 드롭다운(또는 탭)
- 기간: 최근 7일, 30일, 전체 (선택 사항)

## 3-2. 방사형 차트 (하단)

- 축 7개: 체중, 체지방률, 골격근량, 배둘레, 어깨둘레, 가슴둘레, 내장지방지수
- 표시 데이터: 오늘 값(또는 이번 주 평균)을 보정한 점수 (0~100)
- 기준선: 시작(10)과 도전(100)을 겹쳐 표시

## 방사형 차트 보정 수식

$점수 = 10 + \frac{현재값 - 시작값}{목표값 - 시작값} \times 90$

| 값 | 점수 |
|---|---|
| 현재 = 시작 | 10 |
| 현재 = 목표 | 100 |
